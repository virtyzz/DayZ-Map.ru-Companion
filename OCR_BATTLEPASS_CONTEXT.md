# Контекст: внешний трекер Battle Pass для DayZ

Дата: 2026-08-24

## Запрос

Пользователь — обычный игрок на чужом сервере DayZ. Цель: вывести поверх игры локальный оверлей с актуальным состоянием собственного Battle Pass: уровень, XP и прогресс квестов. Информация должна обновляться во время игры.

## Что было проверено

В папке `yw bp client` находятся исходники клиентской части Battle Pass.

- При открытии меню БП клиент отправляет серверу RPC `RequestSync`.
- Сервер синхронизирует на клиент настройки, сезон, магазин, личные данные и таблицу лидеров.
- Личные данные `YWBPPlayerData` включают: `Level`, `XP`, `Coins`, `HasPremium`, активные дневные/недельные задания и массив `Tasks`.
- Для каждого задания `YWBPTaskProgress` содержит ID, период, текущий `Progress`, цель (`RolledTargetAmount`), XP-награду, флаги `Completed` и `RewardClaimed`.
- Клиентское меню показывает прогресс заданий в виде `progress/required`.

Полезные файлы:

- `scripts/5_mission/missiongameplay.c` — отправка `RequestSync` при открытии БП.
- `scripts/4_world/plugins/pluginbase/YWBPClientRPC.c` — приём `SyncPlayerData` и других RPC.
- `scripts/3_game/YWBPPlayerData.c` — структура персонального прогресса.
- `scripts/4_world/gui/YWBPMenu.c` — отображение уровня, XP и заданий.

## Вывод по встроенному экспорту

В клиентском моде **нет** готового внешнего API, HTTP-запросов, JSON-экспорта или записи прогресса в лог/файл. Синхронизированные данные живут в памяти клиента DayZ.

Для полноценного экспорта в файл/сокет нужно было бы добавить клиентский мод, который перехватывает `SyncPlayerData` и сохраняет данные. Но у пользователя нет доступа к серверу. На чужом сервере самостоятельно изменённый или добавленный клиентский PBO обычно не пройдёт проверку набора модов/подписей, поэтому этот путь не подходит.

Не следует читать память игры, внедрять DLL/DirectX-оверлей или перехватывать игровой сетевой трафик: это ненадёжно и может конфликтовать с BattlEye либо правилами сервера.

## ModernQuestCustom

Проверена папка `ModernQuestCustom`.

- Это главным образом серверная надстройка ModernQuests.
- События начала, отмены и завершения квестов, обработчики наград и connector выполняются под `#ifdef SERVER`.
- Есть номера RPC (`SENC_ACTIVE_QUESTS`, `SYNC_DB` и т. д.), но нет клиентского экспортёра, обработчика сохранения в файл или публичного API.
- Серверный `DiscordAPI_Hook` требует параметров запуска сервера и не может использоваться обычным игроком.

Итог: этот мод не создаёт доступного игроку канала экспорта. Он лишь может дать более удобный экран книги квестов для распознавания OCR.

## Рекомендованное решение: внешний OCR-трекер

Сделать отдельное локальное приложение, без модификации DayZ и без доступа к серверу:

1. Пользователь открывает Battle Pass в игре.
2. По горячей клавише приложение делает скриншот окна DayZ или заранее заданных областей БП.
3. OCR считывает уровень, XP и строки заданий со счётчиками вида `12/50`.
4. Приложение сохраняет последнее распознанное состояние локально.
5. Отдельное прозрачное always-on-top окно отображает эти данные поверх игры.

Рекомендуемый первый этап — обновление по горячей клавише, а не постоянный OCR: это проще, легче для ПК и исключает распознавание обычного игрового экрана. Позже можно добавить автоматическое определение открытого окна БП.

Ограничение OCR: считываются только открытые пользователем вкладки и страницы. Для актуализации дневных, недельных и сезонных заданий нужно открыть соответствующие вкладки и пролистать все страницы хотя бы один раз. Трекер будет хранить последнее считанное состояние.

## Следующий запрос для нового чата

Нужно спроектировать и реализовать внешний OCR-трекер Battle Pass для DayZ: локальное приложение, скриншоты только экрана/окна, распознавание уровня/XP/квестов после горячей клавиши, хранение результата и прозрачный always-on-top оверлей. Не использовать чтение памяти, DLL-инъекцию, сетевой перехват или изменение модов DayZ.
